# 默认账号修改流程验收

本次生成固定 Playwright 脚本，仅使用合成账号、合成 token 和隔离 API。前端由本地 Vite 启动；所有 API 和 WebSocket 均在测试浏览器中拦截，不连接远端业务服务。

1. 登录响应 `reset_account:true`：先进入 `/web/desktop`，再显示三个输入框；保存时解密请求应得到新用户名、新密码和固定旧密码 `admin`；成功后清除旧登录态并回到登录页。
2. 登录响应 `reset_account:false`：进入桌面，不显示修改弹窗。
3. 两次密码不一致或保留 `admin/admin`：提示错误、不发送修改请求；Escape 不可关闭，刷新仍显示弹窗。
4. 修改接口返回预期 HTTP 400：显示接口错误，保留输入及弹窗，继续停留桌面。

每项测试独立准备 RSA 密钥及网络夹具；所有动作通过网络守卫执行，无重试、自动修复或共享业务数据。后续执行 `make -C .e2e-strict run`。
